📌 Uso de la consola: conceptos básicos

La consola o línea de comandos es una herramienta que permite interactuar con el sistema operativo mediante texto. A través de comandos puedes navegar por carpetas, crear archivos y directorios, moverte entre rutas y gestionar archivos de forma rápida y precisa, sin necesidad de una interfaz gráfica.

Conceptos clave aprendidos:

Directorio (carpeta): contenedor que organiza archivos y otros directorios.

Ruta (path): ubicación de un archivo o directorio.

Ruta absoluta: empieza desde la raíz (/).

Ruta relativa: depende del directorio actual.

Directorio actual: carpeta en la que estás trabajando en ese momento.

Consola/terminal: interfaz donde se escriben y ejecutan comandos.

Comandos: instrucciones que el sistema interpreta y ejecuta.

🧾 Principales comandos usados en la unidad
🔹 Navegación

pwd
Muestra la ruta del directorio actual.

ls
Lista los archivos y carpetas del directorio actual.

ls -l → lista detallada

ls -a → incluye archivos ocultos

cd nombre_directorio
Cambia al directorio indicado.

cd ..
Sube un nivel en la estructura de directorios.

cd /
Va al directorio raíz.

🔹 Creación de directorios y archivos

mkdir nombre_directorio
Crea un nuevo directorio.

touch archivo.txt
Crea un archivo vacío.

mkdir -p ruta/directorio
Crea varios directorios anidados.

🔹 Gestión de archivos y carpetas

rm archivo.txt
Elimina un archivo.

rm -r carpeta
Elimina una carpeta y su contenido.

cp origen destino
Copia archivos o carpetas.

mv origen destino
Mueve o renombra archivos y carpetas.

🔹 Visualización de contenido

cat archivo.txt
Muestra el contenido de un archivo.

clear
Limpia la pantalla de la consola.
