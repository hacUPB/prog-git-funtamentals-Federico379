# **¿Como crear un repositorio remoto?**

Para crear un repositorio remoto en GitHub y sincronizarlo con un repositorio local, primero se debe iniciar sesión en GitHub y hacer clic en New repository, asignar un nombre al repositorio, elegir si será público o privado y crearlo sin agregar README si ya existe un repositorio local. Luego, en la consola, se accede a la carpeta del proyecto donde ya se ejecutó git init y se han hecho commits. A continuación, se vincula el repositorio local con el remoto usando el comando git remote add origin URL_DEL_REPOSITORIO, donde la URL la proporciona GitHub. Después, se asegura que la rama principal se llame main con git branch -M main y finalmente se envían los archivos al repositorio remoto usando git push -u origin main. Desde ese momento, el repositorio local y el remoto quedan sincronizados, y los siguientes cambios se podrán subir con git add, git commit y git push.
