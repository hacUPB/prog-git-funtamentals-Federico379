Para crear un repositorio local con Git, primero se abre la consola y se navega hasta la carpeta del proyecto usando el comando cd; si la carpeta no existe, se puede crear con mkdir. Una vez dentro del directorio del proyecto, se ejecuta git init, lo que inicializa el repositorio y crea la carpeta oculta .git donde Git guardará el historial de cambios. Luego se pueden crear o modificar archivos y agregarlos al área de preparación con git add . o git add nombre_archivo, y finalmente guardar los cambios con git commit -m "mensaje", quedando así creado y funcionando el repositorio local.
